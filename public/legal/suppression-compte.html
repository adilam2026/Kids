Ce qui est supprimé

  • Si vous n’êtes pas le propriétaire de la famille : votre compte (e-mail, prénom, mot de passe, codes de secours, sessions) est supprimé définitivement. La famille et ses données restent pour les autres parents ; les mouvements de points que vous avez saisis restent dans l’historique, sans votre nom.
  • Si vous êtes propriétaire et que d’autres parents ont accès : la suppression est refusée tant que vous n’avez pas nommé un autre propriétaire (dans l’application : Famille › ⋯ › Nommer propriétaire) ou retiré les autres parents.
  • Si vous êtes le seul parent : votre compte et la famille entière sont supprimés : enfants, points, historique, défis, récompenses, invitations. C’est irréversible. Pensez à exporter les données avant (application › Famille › Exporter les données).

Vous pouvez aussi le faire dans l’application : Famille › Supprimer mon compte. Détails : politique de confidentialité.

Demander la suppression

Mot de passe oublié ? Recevez un lien de récupération (ou utilisez un code de secours), puis revenez ici.

Vous êtes le seul parent : la famille et toutes ses données seront aussi supprimées, définitivement.

Impossible de vous connecter ? Écrivez depuis l’adresse du compte à {{CONTACT_EMAIL}} en indiquant « Suppression de compte Petits Héros » : nous vérifierons que la demande vient bien de l’adresse du compte avant de supprimer.
